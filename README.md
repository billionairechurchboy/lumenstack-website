# Lumenstack Website

Marketing website for **Lumenstack**, a software development and digital transformation company.

Static HTML/CSS/JS — no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `work.html` — Our Work (concept case studies)
- `insights.html` — Insights
- `contact.html` — Contact / project enquiry
- `software-development.html` — Software Development landing page

## Notes
- Forms are front-end only; connect a form backend (e.g. Formspree, Netlify Forms) before launch.
- Contact email, phone and social links are placeholders.
- Case studies are fictional concept projects.
